# Nexa IDE — Compiled APK

This directory contains the ready-to-install Android APK:

- **`apk/nexa-ide-debug.apk`** (20 MB)
- **`apk/app-debug.apk`** (20 MB)

### Installation
You can install this APK on any Android device running Android 7.0+ (API 24+) by opening the file or enabling "Install from unknown sources" on your Android device.
